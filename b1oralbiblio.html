📚 DELF B1 - Expression Orale

Interaction : Résoudre un problème à la bibliothèque

📋 CONSIGNE DE L'EXAMEN

🎯 SITUATION :

Vous avez emprunté un livre à la bibliothèque il y a trois semaines. En le rapportant aujourd'hui, vous découvrez qu'il est abîmé (une page est déchirée). Vous allez voir l'agent d'accueil pour résoudre cette situation.

💬 VOTRE OBJECTIF COMMUNICATIF :
  • ✓ Expliquer le problème de manière claire et polie
  • ✓ Comprendre les conséquences et le règlement
  • ✓ Négocier et proposer des solutions
  • ✓ Demander des informations pratiques
⏱️ DURÉE :

Environ 3 à 5 minutes d'interaction

🎭 RÔLE DE L'EXAMINATEUR :

L'examinateur joue le rôle de l'agent de bibliothèque

PARTIE 1 : 💬 DIALOGUE MODÈLE
👤 VOUS :

Bonjour. Je viens rapporter ce livre que j'ai emprunté, mais j'ai un problème. Je viens de remarquer qu'une page est malheureusement déchirée.

🧑‍💼 AGENT :

Bonjour. Je vois, merci de me le signaler. Pouvez-vous me montrer votre carte de bibliothèque et me dire comment c'est arrivé ?

👤 VOUS :

Oui, bien sûr, voici ma carte. En vérité, je ne sais pas exactement. Peut-être que c'est arrivé quand je le transportais dans mon sac. Je suis vraiment désolé.

🧑‍💼 AGENT :

Je comprends. Selon le règlement, lorsqu'un document est endommagé, l'usager est responsable. Il doit soit le remplacer par un exemplaire identique, soit en payer la valeur.

👤 VOUS :

Je vois... Est-ce qu'il y aurait une autre possibilité ? Par exemple, pourrais-je le réparer moi-même avec du ruban adhésif spécial ?

🧑‍💼 AGENT :

Non, malheureusement, les réparations "maison" ne sont pas acceptées car elles abîment souvent le livre à long terme. Il faudrait que vous trouviez le même livre en librairie.

👤 VOUS :

D'accord. Et si je ne le trouve pas ? Devrais-je payer une amende fixe ?

🧑‍💼 AGENT :

Non, ce n'est pas une amende. Il faudrait que vous payiez le prix de remplacement du livre, qui est de 18 euros. En attendant, votre compte est bloqué pour tout nouvel emprunt.

👤 VOUS :

Je comprends. Pourriez-vous me dire où je pourrais trouver ce livre pour l'acheter ? Et, en attendant une solution, serait-il possible d'emprunter un autre livre avec une caution ?

🧑‍💼 AGENT :

Il faudrait que vous vérifiiez dans les librairies du centre-ville. Pour un nouvel emprunt, c'est possible si vous payez la valeur du livre endommagé comme caution. Vous seriez remboursé quand vous rapporteriez le nouveau livre.

👤 VOUS :

Très bien, merci pour ces solutions. Je vais essayer de le trouver dès aujourd'hui.

PARTIE 2 : 📖 VOCABULAIRE ESSENTIEL
Emprunter : Prendre quelque chose (un livre) pour une durée limitée.
Rapporter / Rendre : Ramener quelque chose qu'on a emprunté.
Être abîmé / endommagé : Être en mauvais état, détérioré.
Une page déchirée : Une page qui a un trou ou une déchirure.
Le règlement : L'ensemble des règles officielles.
Être responsable : Devoir assumer les conséquences de ses actes.
Remplacer : Mettre un nouveau livre à la place de l'ancien.
Payer la valeur : Donner l'argent correspondant au prix du livre.
Une amende : Une somme d'argent à payer comme punition (différent de la valeur de remplacement).
Un compte bloqué : Un compte temporairement inactif, on ne peut pas l'utiliser.
Une caution : Une somme d'argent donnée temporairement comme garantie.
PARTIE 3 : 💡 EXPRESSIONS UTILES

🗣️ Expressions fonctionnelles pour l'interaction

Il faut que + [je/vous] + verbe

Pour exprimer une obligation ou une nécessité

💬 "Il faut que je trouve un nouveau livre"
💬 "Il faut que vous payiez 18 euros"
💬 "Il faut que je vérifie en librairie"
Je voudrais que + [vous] + verbe

Pour exprimer un souhait poliment

💬 "Je voudrais que vous m'expliquiez le règlement"
💬 "Je voudrais que vous me disiez où acheter ce livre"
Pourriez-vous... ? / Serait-il possible de... ?

Pour demander quelque chose poliment (conditionnel)

💬 "Pourriez-vous m'expliquer la procédure ?"
💬 "Serait-il possible de payer en plusieurs fois ?"
Est-ce qu'il y aurait... ?

Pour proposer une alternative

💬 "Est-ce qu'il y aurait une autre possibilité ?"
💬 "Est-ce qu'il y aurait un moyen de réduire le coût ?"
💡 Note importante : Ces expressions sont des formules toutes faites. Vous n'avez pas besoin de comprendre toute la grammaire – il suffit de les utiliser telles quelles dans vos conversations !
PARTIE 4 : ✏️ EXERCICES PRATIQUES

Exercice 1 : Utiliser "Il faut que" et "Je voudrais que"

Transforme ces phrases en utilisant les expressions appropriées :

1. Tu dois chercher le livre dans une librairie.

→ Utilise "Il faut que..."

✓ Réponse : "Il faut que je cherche le livre dans une librairie."
(ou "Il faut que tu cherches...")

2. Je dois remplacer le livre endommagé.

→ Utilise "Il faut que..."

✓ Réponse : "Il faut que je remplace le livre endommagé."

3. Vous devez payer la valeur du livre.

→ Utilise "Il faut que..."

✓ Réponse : "Il faut que vous payiez la valeur du livre."

4. Je veux que vous m'expliquez le règlement.

→ Transforme avec "Je voudrais que..." (plus poli)

✓ Réponse : "Je voudrais que vous m'expliquiez le règlement."

5. Je souhaite que vous me donnez des informations.

→ Transforme avec "Je voudrais que..." (plus poli)

✓ Réponse : "Je voudrais que vous me donniez des informations."

6. Situation : Tu parles à l'agent. Tu veux savoir où acheter le livre.

→ Crée une phrase complète avec "Je voudrais que..."

✓ Réponses possibles :
"Je voudrais que vous me disiez où acheter le livre."
"Je voudrais que vous m'indiquiez les librairies du centre-ville."
💡 Astuce : Ces expressions sont très utiles à l'examen ! "Il faut que" montre que vous comprenez l'obligation, et "Je voudrais que" est parfait pour demander poliment quelque chose.

Exercice 2 : Connecteurs logiques

Complète les phrases avec les connecteurs appropriés : donc, ensuite, par contre, en effet, finalement

1. "J'ai découvert que le livre était abîmé. ________, je dois trouver une solution."

✓ Réponse : "donc"

2. "Je voudrais régler ce problème. ________, j'aimerais savoir si je peux emprunter d'autres livres en attendant."

✓ Réponse : "Ensuite" OU "Puis"

3. "Je pourrais le réparer moi-même. ________, le règlement l'interdit."

✓ Réponse : "Par contre" OU "Cependant"

4. "Le livre s'est abîmé dans mon sac. ________, il y avait d'autres objets lourds."

✓ Réponse : "En effet"

5. "J'ai cherché dans plusieurs librairies. ________, j'ai trouvé le dernier exemplaire."

✓ Réponse : "Finalement"

🎬 Interaction en temps réel

L'agent vous dit : "Je suis désolé, mais le livre que vous rapportez est très abîmé. Il faudrait que vous payiez 25 euros pour le remplacer, et votre carte sera bloquée pendant 2 semaines."


Votre mission (3 minutes) :

  • ✓ Réagir à cette annonce
  • ✓ Demander des clarifications
  • ✓ Proposer une solution alternative
  • ✓ Négocier si possible
