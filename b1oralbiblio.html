🎭 Scénario C : À la bibliothèque

Problème avec un livre emprunté

🧑 Ton rôle : Tu as emprunté un livre à la bibliothèque il y a trois semaines. En le rapportant aujourd'hui, tu découvres qu'il est abîmé (une page est déchirée). Tu dois résoudre cette situation avec l'agent d'accueil.
👤 Mon rôle : Je suis l'agent à l'accueil de la bibliothèque.
📋 Contraintes :
  • ✓ Expliquer ce qui est arrivé au livre
  • ✓ Comprendre les conséquences et le règlement de la bibliothèque
  • ✓ Trouver une solution (réparer, remplacer, payer ?)
  • ✓ Demander à emprunter un autre exemplaire ou un autre livre
PARTIE 1 : 💬 DIALOGUE TYPE
👤 USAGER (Toi) :

Bonjour. Je viens rapporter ce livre que j'ai emprunté, mais j'ai un problème. Je viens de remarquer qu'une page est malheureusement déchirée.

🧑‍💼 AGENT (Moi) :

Bonjour. Je vois, merci de me le signaler. Pouvez-vous me montrer votre carte de bibliothèque et me dire comment c'est arrivé ?

👤 USAGER :

Oui, bien sûr, voici ma carte. En vérité, je ne sais pas exactement. Peut-être que c'est arrivé quand je le transportais dans mon sac. Je suis vraiment désolé.

🧑‍💼 AGENT :

Je comprends. Selon le règlement, lorsqu'un document est endommagé, l'usager est responsable. Il doit soit le remplacer par un exemplaire identique, soit en payer la valeur.

👤 USAGER :

Je vois... Est-ce qu'il y aurait une autre possibilité ? Par exemple, pourrais-je le réparer moi-même avec du ruban adhésif spécial ?

🧑‍💼 AGENT :

Non, malheureusement, les réparations "maison" ne sont pas acceptées car elles abîment souvent le livre à long terme. Il faudrait que vous trouviez le même livre en librairie.

👤 USAGER :

D'accord. Et si je ne le trouve pas ? Devrais-je payer une amende fixe ?

🧑‍💼 AGENT :

Non, ce n'est pas une amende. Il faudrait que vous payiez le prix de remplacement du livre, qui est de 18 euros. En attendant, votre compte est bloqué pour tout nouvel emprunt.

👤 USAGER :

Je comprends. Pourriez-vous me dire où je pourrais trouver ce livre pour l'acheter ? Et, en attendant une solution, serait-il possible d'emprunter un autre livre avec une caution ?

🧑‍💼 AGENT :

Il faudrait que vous vérifiiez dans les librairies du centre-ville. Pour un nouvel emprunt, c'est possible si vous payez la valeur du livre endommagé comme caution. Vous seriez remboursé quand vous rapporteriez le nouveau livre.

👤 USAGER :

Très bien, merci pour ces solutions. Je vais essayer de le trouver dès aujourd'hui.

PARTIE 2 : 📖 VOCABULAIRE ESSENTIEL
Emprunter : Prendre quelque chose (un livre) pour une durée limitée.
Rapporter / Rendre : Ramener quelque chose qu'on a emprunté.
Être abîmé / endommagé : Être en mauvais état, détérioré.
Une page déchirée : Une page qui a un trou ou une déchirure.
Le règlement : L'ensemble des règles officielles.
Être responsable : Devoir assumer les conséquences de ses actes.
Remplacer : Mettre un nouveau livre à la place de l'ancien.
Payer la valeur : Donner l'argent correspondant au prix du livre.
Une amende : Une somme d'argent à payer comme punition (différent de la valeur de remplacement).
Un compte bloqué : Un compte temporairement inactif, on ne peut pas l'utiliser.
Une caution : Une somme d'argent donnée temporairement comme garantie.
PARTIE 3 : ✏️ EXERCICES D'EXPRESSION

Exercice 1 : Formules de politesse

1. Pour expliquer un problème de manière polie et assumée :

✓ Réponses possibles :
"Bonjour, je dois vous signaler que le livre que je rends est endommagé."
OU "J'ai le regret de vous informer qu'une page du livre est déchirée."

2. Pour demander le règlement précis :

✓ Réponses possibles :
"Pourriez-vous m'expliquer clairement ce que je dois faire dans cette situation ?"
OU "Est-ce que vous pourriez me dire quelles sont les procédures ?"

3. Pour proposer une solution :

✓ Réponses possibles :
"Est-ce qu'il y aurait une autre possibilité, comme de le réparer ?"
OU "Serait-il possible de payer en plusieurs fois ?"
💡 Astuce : Utilise le conditionnel ("pourriez-vous", "serait-il possible") pour être plus poli.

Exercice 2 : Réagir aux problèmes

1. L'agent dit : "Je suis désolé, mais notre règlement est très strict, vous devez payer 25 euros."

Comment réagis-tu ?

✓ Réponses possibles :
"Je comprends, mais est-ce qu'il n'y a vraiment aucune exception ? Je n'ai pas cette somme sur moi aujourd'hui."
OU "Pourriez-vous vérifier s'il existe un tarif réduit ou un paiement échelonné ?"

2. L'agent dit : "Ce livre n'est plus édité, vous ne pourrez pas le remplacer."

Comment réagis-tu ?

✓ Réponses possibles :
"Est-ce que je pourrais acheter un livre similaire de même valeur à la place ?"
OU "Et si je faisais un don à la bibliothèque du montant équivalent ?"

3. L'agent dit : "Votre carte sera bloquée pendant un mois."

Comment réagis-tu ?

✓ Réponses possibles :
"Un mois, c'est très long. Y aurait-il un moyen de réduire cette durée si je règle le problème rapidement ?"
OU "Est-ce que vous pourriez faire une exception, c'est la première fois que cela m'arrive ?"
PARTIE 4 : 📚 RÉVISION GRAMMATICALE

"Il faut que" + SUBJONCTIF

Cette structure s'utilise principalement pour :

  • ✓ Exprimer une nécessité ou une obligation
  • ✓ Indiquer ce qui est nécessaire dans une situation
  • ✓ Formuler une contrainte administrative ou règlementaire
Exemples dans le dialogue :
  • "Il faudrait que vous trouviez le même livre en librairie." (nécessité)
  • "Il faudrait que vous payiez le prix de remplacement." (obligation)
  • "Il faudrait que vous vérifiiez dans les librairies du centre-ville." (conseil fort)

Formation : "Il faut que" + verbe au subjonctif présent

Verbe Subjonctif (je) Subjonctif (vous) Utilisation dans le scénario
Trouver que je trouve que vous trouviez Exprimer la nécessité de remplacer
Payer que je paie que vous payiez Indiquer l'obligation de règlement
Vérifier que je vérifie que vous vérifiiez Donner une instruction précise
Rapporter que je rapporte que vous rapportiez Préciser une condition
💡 Astuce pour le DELF : Utilise "il faut que je..." pour montrer que tu as compris les obligations. Par exemple : "D'accord, donc il faut que je trouve un exemplaire identique."

Exercice 3 : Pratique de "Il faut que" + subjonctif

Transforme ces obligations en utilisant "il faut que" + subjonctif :

1. "Je dois remplacer le livre."

✓ Réponse : "Il faut que je remplace le livre."

2. "Vous devez payer 18 euros."

✓ Réponse : "Il faut que vous payiez 18 euros."

3. "Tu dois vérifier en librairie."

✓ Réponse : "Il faut que tu vérifies en librairie."

4. "Nous devons respecter le règlement."

✓ Réponse : "Il faut que nous respections le règlement."

Exercice 4 : Connecteurs logiques

Complète les phrases avec les connecteurs appropriés : donc, ensuite, par contre, en effet, finalement

1. "J'ai découvert que le livre était abîmé. ________, je dois trouver une solution."

✓ Réponse : "donc"

2. "Je voudrais régler ce problème. ________, j'aimerais savoir si je peux emprunter d'autres livres en attendant."

✓ Réponse : "Ensuite" OU "Puis"

3. "Je pourrais le réparer moi-même. ________, le règlement l'interdit."

✓ Réponse : "Par contre" OU "Cependant"

4. "Le livre s'est abîmé dans mon sac. ________, il y avait d'autres objets lourds."

✓ Réponse : "En effet"

5. "J'ai cherché dans plusieurs librairies. ________, j'ai trouvé le dernier exemplaire."

✓ Réponse : "Finalement"
