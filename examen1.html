Texte de référence : la cabane au fond du jardin

Le petit garçon ouvre la porte de la cabane. Elle est vieille et abandonnée depuis des années. Il découvre une magnifique boîte en bois, couverte de poussière. Soudain, il entend un bruit étrange derrière lui. Il se retourne rapidement, mais il ne voit rien. Le vent souffle fort et les feuilles mortes tourbillonnent dans le jardin.

Rappels essentiels

🔵 Rappel 1 — Les temps de l'indicatif

  • Présent : action en cours. Je mange.
  • Imparfait : action longue, description. Je mangeais.
  • Futur simple : action à venir. Je mangerai.
  • Passé composé : action passée terminée. J'ai mangé.

🟣 Rappel 2 — La formation des mots

Un mot peut être construit à partir d'un radical (la base) auquel on ajoute :

🔴 Le PRÉFIXE → devant le radical

Il se place devant le radical. Il change le sens du mot, mais ne change pas sa nature.

im- + possible = impossible

possible (adjectif) → impossible (adjectif) : la nature ne change pas, mais le sens devient négatif.

Autres exemples :

  • re- + lire = relire (lire de nouveau)
  • mal- + heureux = malheureux (pas heureux)
  • in- + visible = invisible (qu'on ne voit pas)
  • dé- + faire = défaire (enlever ce qui est fait)
  • pré- + histoire = préhistoire (avant l'histoire)
🟢 Le SUFFIXE → derrière le radical

Il se place derrière le radical. Il change la nature du mot et apporte une nuance de sens.

laver + -age = lavage

laver (verbe) → lavage (nom) : la nature change !

Autres exemples :

  • blanc + -ir = blanchir (adjectif → verbe)
  • dent + -iste = dentiste (nom → nom de métier)
  • rapide + -ment = rapidement (adjectif → adverbe)
  • laver + -able = lavable (verbe → adjectif)
  • jardin + -ier = jardinier (nom → nom de métier)

À retenir

PRÉFIXE + RADICAL + SUFFIXE

Exemple complet : in- + lav + -able = inlavable (qui ne peut pas être lavé)

🟢 Rappel 3 — La nature des mots

  • Mots variables : nom, adjectif, verbe, déterminant, pronom.
  • Mots invariables : adverbe, préposition, conjonction.

🟠 Rappel 4 — Le GN et l'accord de l'adjectif

  • GN : déterminant + nom noyau (+ adjectifs). une belle cabane
  • Nom noyau : le nom principal du GN.
  • Accord de l'adjectif : en genre et en nombre avec le nom. des feuilles mortes
