semaines 2 → 8 · rappels + exercices possifs & démonstratifs

⚓ auxiliaires être / avoir

AVOIRmanger, finir, prendre, voir, acheter, mettre… ÊTRE14 mouv. + pronominaux : aller, venir, partir, arriver, naître, mourir, tomber, rester, monter, descendre, sortir, entrer, retourner, rentrer, devenir, revenir

👆 Accord avec être : elle est allée, ils sont partis, nous nous sommes promené(e)s

📝 Exercice 1 – Complète au passé composé (être/avoir + accord si nécessaire)
1. sommes allé(e)s (être + accord éventuel)
2. s’est reposée (pronominal, être, accord fém. sing.)
3. avez acheté (avoir, pas d’accord)
4. sont parties (être, accord fém. plur.)
5. a descendu (avoir, car COD « les valises »)

⏩ futur proche & modaux

🚀 Exercice 2 – Forme des phrases avec l’expression indiquée
a) Je vais acheter un appartement.
b) Nous devons finir le travail.
c) Tu ne peux pas venir à la fête.
d) Elles veulent partir en voyage.

🔁 pronoms COD / COI

🔤 Exercice 3 – Remplace par le, la, les, lui, leur
1. les
2. lui
3. l’
4. leur
5. l’ (car COD, attention : « je l’ai embrassée » avec accord car placé avant)

⚖️ comparatifs

📊 Exercice 4 – Complète avec plus… que, moins… que, aussi… que
1. plus … que (ou aussi … que, mais Tokyo est effectivement plus grand)
2. plus … que (ou moins … que si on inverse la phrase)
3. aussi … que / plus … que (selon l’opinion)

🔄 imparfait / conditionnel

🧩 Exercice 5 – Imparfait ou conditionnel ? Conjugue
1. étais / jouais (imparfait habitude)
2. voudrais (conditionnel politesse)
3. faisait / sommes sortis (imparfait description + PC)
4. devrais (conditionnel conseil)

🔐 pronoms possessifs

💡 Exercice 7 – Remplace avec le mien, la mienne, les miens, les miennes, le tien… (attention accords)
1. le mien (sac = masculin)
2. la tienne (voiture = féminin)
3. les miennes (clés = féminin pluriel)
4. les tiennes (lunettes = fém. plur.)
5. le nôtre (appartement = masc. sing.)
