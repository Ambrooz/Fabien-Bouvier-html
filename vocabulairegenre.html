📚 Les Adjectifs Démonstratifs

ce • cet • cette • ces • avec 80 mots de vocabulaire A1-A2

👋 Bonjour ! Aujourd'hui, nous allons apprendre à dire :

"CE livre" • "CET homme" • "CETTE femme" • "CES enfants"

Les adjectifs démonstratifs servent à montrer, désigner une personne ou une chose.

📖 Point de grammaire

🎯 Règle générale

L'adjectif démonstratif s'accorde en genre (masculin/féminin) et en nombre (singulier/pluriel) avec le nom qu'il accompagne.

Masculin singulier

CE

Devant un nom masculin qui commence par une consonne.

🔹 ce livre
🔹 ce chat
🔹 ce garçon

Masculin singulier

CET

Devant un nom masculin qui commence par une voyelle ou un h muet.

🔹 cet homme
🔹 cet arbre
🔹 cet hôtel

Féminin singulier

CETTE

Devant tous les noms féminins.

🔹 cette femme
🔹 cette maison
🔹 cette école

Pluriel

CES

Pour tous les noms au pluriel (masculin et féminin).

🔹 ces livres
🔹 ces femmes
🔹 ces enfants

💡 ASTUCE VISUELLE

CE → consonne
CET → voyelle/h
CETTE → féminin
CES → pluriel

✍️ Exercices pratiques

Complétez avec ce, cet, cette ou ces. Cliquez sur "Vérifier" pour voir vos réponses.

Score: 0/15

1. Regarde ___ livre sur la table. (masculin, consonne)

Réponse correcte : "ce" livre (livre est masculin et commence par une consonne)
Exemple : Ce livre est intéressant.

2. J'aime beaucoup ___ arbre dans le jardin. (masculin, commence par une voyelle)

Réponse correcte : "cet" arbre (arbre est masculin et commence par une voyelle)
Exemple : Cet arbre est grand.

3. ___ femme est très gentille. (féminin singulier)

Réponse correcte : "cette" femme (femme est féminin)
Exemple : Cette femme est ma mère.

4. ___ enfants jouent dans le parc. (pluriel)

Réponse correcte : "ces" enfants (enfants est pluriel)
Exemple : Ces enfants sont contents.

5. Tu as vu ___ homme avec un chapeau ? (masculin, h muet)

Réponse correcte : "cet" homme (homme commence par un h muet, on utilise cet)
Exemple : Cet homme est mon voisin.

6. J'habite dans ___ maison depuis 5 ans. (féminin singulier)

Réponse correcte : "cette" maison
Exemple : Cette maison est confortable.

7. ___ ordinateur ne fonctionne plus. (masculin, voyelle)

Réponse correcte : "cet" ordinateur
Exemple : Cet ordinateur est lent.

8. ___ voiture est garée devant la porte. (féminin singulier)

Réponse correcte : "cette" voiture
Exemple : Cette voiture est rouge.

9. Je voudrais acheter ___ livres. (pluriel)

Réponse correcte : "ces" livres
Exemple : Ces livres sont intéressants.

10. ___ école est très grande. (féminin singulier, commence par une voyelle mais reste féminin)

Réponse correcte : "cette" école (même avec une voyelle, école est féminin donc cette)
Exemple : Cette école est moderne.

11. ___ hôtel est très confortable. (masculin, h muet)

Réponse correcte : "cet" hôtel (h muet, masculin)
Exemple : Cet hôtel a une piscine.

12. ___ chaises sont cassées. (pluriel)

Réponse correcte : "ces" chaises
Exemple : Ces chaises sont vieilles.

13. ___ crayon est à moi. (masculin, consonne)

Réponse correcte : "ce" crayon
Exemple : Ce crayon est rouge.

14. ___ fleurs sont magnifiques. (pluriel)

Réponse correcte : "ces" fleurs
Exemple : Ces fleurs sentent bon.

15. ___ ami s'appelle Pierre. (masculin, voyelle)

Réponse correcte : "cet" ami (ami masculin, commence par une voyelle)
Exemple : Cet ami est sympa.

📋 Tableau récapitulatif

Genre / Nombre Démonstratif Exemple Règle
Masculin singulier (consonne) CE ce livre, ce chat Devant une consonne
Masculin singulier (voyelle/h muet) CET cet arbre, cet homme Devant une voyelle ou h muet
Féminin singulier CETTE cette femme, cette maison Tous les noms féminins
Pluriel CES ces livres, ces femmes Tous les noms au pluriel

⚠️ Points importants à retenir

🔊

Le h muet

Le h muet se comporte comme une voyelle :

cet homme (h muet)
ce héros (h aspiré, on dit "ce héros")

🎯

Féminin toujours "cette"

Même si le mot commence par une voyelle :

cette école (pas "cet école")
cette amie (féminin)

📌

Pluriel universel

"ces" fonctionne pour tous les noms au pluriel :

ces hommes
ces femmes
ces enfants
