📝 Leçon — Les temps du récit

☀️ Les temps utilisés dans le texte

Dans ce récit, nous avons utilisé cinq temps verbaux pour raconter l'histoire de manière naturelle :

  • Le présent → pour les faits généraux et les situations actuelles
  • Le passé composé → pour les actions ponctuelles terminées
  • L'imparfait → pour les descriptions et les habitudes dans le passé
  • Le futur proche → pour les prévisions et les actions à venir
  • Le plus-que-parfait → pour une action antérieure à une autre dans le passé

📋 Le présent de l'indicatif

On utilise le présent pour parler :

  • de ce qui se passe maintenant : Nous suivons les recommandations.
  • de faits habituels : Chaque été, la France connaît des épisodes de chaleur.
  • de vérités générales : La solidarité fait la différence.

📋 Le passé composé

On utilise le passé composé pour parler d'actions terminées dans le passé.
Formation : avoir ou être (au présent) + participe passé.

exemple : Les températures ont grimpé jusqu'à 42 degrés.
exemple : Les records se sont succédé jour après jour.

📋 L'imparfait

On utilise l'imparfait pour :

  • décrire une situation dans le passé : Le soleil brûlait le bitume.
  • parler d'habitudes : Nous restions à l'intérieur.
  • décrire un décor : Les rues se vidaient vers midi.

📋 Le futur proche

On utilise le futur proche pour parler de ce qui va arriver bientôt.
Formation : aller (au présent) + infinitif.

exemple : Cette situation va durer encore plusieurs jours.
exemple : Un orage va arriver en fin de semaine.

📋 Le plus-que-parfait

On utilise le plus-que-parfait pour une action antérieure à une autre action passée.
Formation : avoir ou être (à l'imparfait) + participe passé.

exemple : Mes parents avaient fermé tous les volets.
exemple : Mon père avait ressorti le vieux ventilateur du grenier.

💡 Astuce : Comment choisir le bon temps ?

  • Présent → action maintenant ou habituelle
  • Passé composé → action terminée, souvent avec marqueur de temps
  • Imparfait → description ou habitude dans le passé
  • Futur proche → action qui va se passer bientôt
  • Plus-que-parfait → action avant une autre dans le passé

Exercice 1 — Choisissez le temps qui convient

Choisissez le temps verbal le plus adapté à la situation.

1. Chaque été, les températures ______ très élevées.

2. Hier, nous ______ tous les volets pour garder la fraîcheur.

3. Demain, un orage ______ pour soulager la région.

4. Pendant la canicule, les gens ______ dans les parcs le soir.

5. Ma grand-mère me ______ toujours des histoires de son enfance.

1. dépassent (présent — fait habituel)
2. avons fermé (passé composé — action terminée hier)
3. va arriver (futur proche — prévision pour demain)
4. se promenaient (imparfait — description d'une habitude passée)
5. racontait (imparfait — habitude dans le passé)

Exercice 2 — Conjuguez le verbe au temps indiqué

2. (boire — passé composé) Nous ______ beaucoup d'eau hier. ➜
3. (s'inquiéter — présent) Les agriculteurs ______ pour leurs récoltes. ➜
4. (aller — futur proche) Nous ______ à la piscine demain. ➜
5. (jouer — imparfait) Quand j'étais petit, je ______ dans le jardin. ➜
1. fait (présent — il fait chaud)
2. avons bu (passé composé — action terminée hier)
3. s'inquiètent (présent — ils s'inquiètent)
4. allons aller (futur proche — action future)
5. jouais (imparfait — habitude passée)

Exercice 3 — Vrai ou Faux ?

Dites si les affirmations suivantes sont vraies (V) ou fausses (F) selon le texte.

1. Les températures ont dépassé 50 degrés la semaine dernière.

2. Les oiseaux cherchaient de l'ombre pendant la canicule.

3. Le grand-père raconte que les étés étaient plus chauds avant.

4. Un orage va arriver en fin de semaine selon les prévisions.

5. Les scientifiques vont arrêter leurs recherches sur le climat.

1. Faux — « Les températures ont grimpé jusqu'à 42 degrés. »
2. Vrai — « Les oiseaux cherchaient désespérément un peu d'ombre. »
3. Faux — Il raconte que les étés étaient moins chauds avant.
4. Vrai — « Un orage va arriver en fin de semaine. »
5. Faux — Cette information n'est pas dans le texte.

💬 Expressions pour parler de la chaleur et de la météo

Pourquoi ces expressions ? La canicule est un phénomène de plus en plus fréquent. Ces expressions vous aideront à parler du temps, exprimer ce que vous ressentez face à la chaleur, et à donner ou recevoir des conseils pour mieux vivre ces périodes difficiles.
Sensation
Être en sueur
To be sweating
Avec cette chaleur, je suis en sueur toute la journée.
With this heat, I'm sweating all day long.
Prévision
Il va pleuvoir
It's going to rain
La météo dit qu'il va pleuvoir demain matin.
The weather forecast says it's going to rain tomorrow morning.
Conseil
Rester à l'ombre
To stay in the shade
Pour éviter le coup de chaleur, il vaut mieux rester à l'ombre.
To avoid heatstroke, it's better to stay in the shade.
Soulagement
Ça me fait du bien
It does me good
Une douche fraîche, ça me fait vraiment du bien !
A cool shower really does me good!
Météo
La température monte
The temperature is rising
Depuis ce matin, la température monte sans arrêt.
Since this morning, the temperature has been rising non-stop.
Sensation
Avoir très chaud
To be very hot
Dans cette pièce, j'ai très chaud. On peut ouvrir la fenêtre ?
In this room, I'm very hot. Can we open the window?
Précaution
Éviter les efforts
To avoid exertion
Pendant la canicule, il faut éviter les efforts physiques.
During a heatwave, you should avoid physical exertion.
Futur
Ça va changer
It's going to change
Ne t'inquiète pas, le temps va changer la semaine prochaine.
Don't worry, the weather is going to change next week.
Conseil
Se rafraîchir
To cool down
Je vais à la piscine pour me rafraîchir un peu.
I'm going to the pool to cool down a bit.
Espoir
J'espère que
I hope that
J'espère que la chaleur va diminuer rapidement.
I hope the heat will go down quickly.
Réaction
Quelle chaleur !
What heat!
Quelle chaleur ! Je vais boire un verre d'eau fraîche.
What heat! I'm going to drink a glass of cool water.
Précaution
Porter un chapeau
To wear a hat
Quand il fait très chaud, il faut porter un chapeau et des lunettes de soleil.
When it's very hot, you should wear a hat and sunglasses.

💡 Astuce · Pro tip

En France, les canicules sont de plus en plus fréquentes en été.
Pour parler du temps, on utilise souvent "il fait + adjectif" (chaud, froid, beau, mauvais).
Pour parler du passé, on utilise le passé composé pour les actions terminées et l'imparfait pour les descriptions.
Pour parler du futur, on utilise le futur proche avec aller.
N'oubliez pas les conseils de sécurité : boire de l'eau, rester à l'ombre et éviter les efforts.
