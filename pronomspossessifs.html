Les Pronoms Possessifs et Démonstratifs

Leçon simple et efficace avec exercices interactifs

Une journée au bureau

Hier, j'ai travaillé sur mon projet. Ma collègue Sophie est venue me voir. Elle avait besoin de ses documents.

J'ai regardé sur mon bureau. Il y avait deux dossiers. Celui-ci est à moi, mais celui-là est à Sophie. Ses papiers étaient dans le deuxième dossier.

Ensuite, nous avons comparé nos présentations. La mienne était simple, la sienne était plus détaillée. Le chef a préféré la sienne.

Finalement, j'ai rangé mes affaires et je suis parti. C'était une bonne journée de travail.

Les Pronoms Possessifs

Ils indiquent à qui appartient quelque chose.

Personne Masculin Singulier Féminin Singulier Masculin Pluriel Féminin Pluriel
Je (moi) le mien la mienne les miens les miennes
Tu (toi) le tien la tienne les tiens les tiennes
Il/Elle (lui) le sien la sienne les siens les siennes
Nous le nôtre la nôtre les nôtres les nôtres
Vous le vôtre la vôtre les vôtres les vôtres
Ils/Elles (eux) le leur la leur les leurs les leurs

Exemples :

"Ce stylo est le mien." (mon stylo)

"Cette voiture est la sienne." (sa voiture)

"Ces livres sont les nôtres." (nos livres)

Les Pronoms Démonstratifs

Ils montrent ou désignent quelque chose.

Type Singulier Pluriel Exemple
Masculin celui ceux Ce livre est intéressant, mais celui est meilleur
Féminin celle celles Cette chaise est confortable, celle ne l'est pas
Avec -ci (près) celui-ci / celle-ci ceux-ci / celles-ci Celui-ci est ici, celui-là est là-bas
Avec -là (loin) celui-là / celle-là ceux-là / celles-là Je préfère celle-là, pas celle-ci

Exemples :

"J'ai deux crayons. Celui-ci écrit bien." (ce crayon ici)

"Regarde ces fleurs. Celles-là sont plus belles." (ces fleurs là-bas)

Exercices

Exercice 1 : Pronoms possessifs

Complète avec le bon pronom possessif.

1. J'adore ta nouvelle collection. Est-ce que je peux voir ? (tes derniers croquis)

Réponse : les tiens

Explication : "les tiens" remplace "tes derniers croquis" (masculin pluriel, 2ème personne).

2. Mon téléphone est neuf, mais est ancien. (son téléphone)

Réponse : le sien

Explication : "le sien" remplace "son téléphone" (masculin singulier, 3ème personne).

3. Notre maison est grande, est petite. (votre maison)

Réponse : la vôtre

Explication : "la vôtre" remplace "votre maison" (féminin singulier, 2ème personne du pluriel).

Exercice 2 : Pronoms démonstratifs

Complète avec le bon pronom démonstratif.

1. J'ai deux cafés. est chaud, est froid.

Réponse : Celui-ci / celui-là

Explication : "celui-ci" désigne le café proche, "celui-là" désigne le café plus éloigné.

2. Ces robes sont belles, mais je préfère . (les robes là-bas)

Réponse : celles-là

Explication : "celles-là" remplace "les robes là-bas" (féminin pluriel, éloigné).

3. Parmi tous ces livres, est le plus intéressant.

Réponse : celui-ci

Explication : "celui-ci" désigne un livre spécifique (masculin singulier, proche).

💡 Astuces

Pronoms Possessifs

Ils répondent à la question : "À qui est-ce ?"

Ex: "Ce livre est à moi" → "C'est le mien"

Pronoms Démonstratifs

Ils répondent à la question : "Lequel ?"

-ci = proche
-là = éloigné

🎯 Pour retenir

Possessif : mon, ton, son → le mien, le tien, le sien

Démonstratif : ce, cette → celui, celle

📝 Exemples rapides

"Ma voiture" → "C'est la mienne"

"Cette chaise" → "Je prends celle-ci"
