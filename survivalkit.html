💬 Expressions clés / Key expressions
👋 Bonjour / Bonsoir → à l'entrée d'un lieu
Hello / Good evening → when entering a place
🙏 S'il vous plaît / Merci / Je vous en prie / Avec plaisir → politesse de base
Please / Thank you / You're welcome / My pleasure → basic politeness
❓ Est-ce que vous parlez anglais ? → pour demander de l'aide
Do you speak English? → to ask for help
🗺️ Où est… ? / Où sont… ? → pour demander son chemin
Where is…? / Where are…? → to ask for directions
➡️ À gauche / À droite / Tout droit → indications de direction
Left / Right / Straight ahead → directions
📍 Après / Avant / Devant / Derrière → se repérer dans l'espace
After / Before / In front of / Behind → spatial reference
🍽️ Je voudrais… / L'addition, s'il vous plaît → au restaurant
I would like… / The check, please → at the restaurant
🚨 Au secours ! / J'ai besoin d'aide → urgence
Help! / I need help → emergency

✍️ Jeu 2 : Complétez / Fill in the blank
📝 Situation → expression ? / Situation → expression?
1. Vous entrez dans une boulangerie. → ✅ Bonjour You enter a bakery. →
2. Quelqu'un vous aide. → ✅ Merci Someone helps you. →
3. Quelqu'un vous remercie. → ✅ Je vous en prie / Avec plaisir Someone thanks you. →
4. Vous voulez demander si la personne parle anglais. → ✅ Est-ce que vous parlez anglais ? You want to ask if the person speaks English. →
5. Vous cherchez les toilettes. → ✅ Où sont les toilettes ? You are looking for the restrooms. →
6. Au café, vous voulez commander un espresso. → ✅ Je voudrais un café At the café, you want to order an espresso. →
7. Vous êtes perdu. → ✅ Je suis perdu(e) You are lost. →
8. Vous voulez l'addition. → ✅ L'addition, s'il vous plaît You want the check. →
9. Urgence : vous avez besoin d'aide. → ✅ Au secours ! Emergency: you need help. →
10. Indiquez la direction : tournez à main gauche. → ✅ À gauche Give the direction: turn left. →
11. Continuez sans tourner. → ✅ Tout droit Keep going without turning. →
12. La banque est juste après la boulangerie. → ✅ Après The bank is just after the bakery. →
13. Le parking est devant l'hôtel. → ✅ Devant The parking lot is in front of the hotel. →
14. Le jardin est derrière la maison. → ✅ Derrière The garden is behind the house. →
