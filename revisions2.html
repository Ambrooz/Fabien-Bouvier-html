Présent de l'indicatif

Ce qui est vrai maintenant, en ce moment ou en général
✦ Action en cours ✦ Vérité générale ✦ Habitude ✦ Maintenant
Formation
-er : je chante, tu chantes, il chante, nous chantons, vous chantez, ils chantent
-ir : je nourris, tu nourris, il nourrit, nous nourrissons, vous nourrissez, ils nourrissent
-re : je perds, tu perds, il perd, nous perdons, vous perdez, ils perdent
⚠️ Irréguliers : être, avoir, aller, faire, pouvoir, vouloir, venir, savoir
Verbes modèles
jechante / nourris / perds
tuchantes / nourris / perds
il/ellechante / nourrit / perd —
nouschantons / nourrissons / perdons
vouschantez / nourrissez / perdez
ils/elleschantent / nourrissent / perdent
→
Chaque dimanche, mon voisin tond la pelouse.
habitude
→
Nous construisons une cabane dans le jardin.
en cours
→
L'eau gèle à 0 degré Celsius.
vérité générale
✏️ Exercice – Conjugue au présent
1. Tu (perdre) souvent tes clés.
2. Nous (nourrir) les chats errants.
3. Ils (devenir) grands trop vite.
4. Elle (pouvoir) danser toute la nuit.
5. Vous (savoir) nager ?
6. Je (tenir) la porte pour toi.
  1. perds
  2. nourrissons
  3. deviennent
  4. peut
  5. savez
  6. tiens

Participe présent

-ant · Simultanéité, cause, condition
✦ En + part. présent (gérondif)✦ Simultanéité✦ Cause / Manière
Formation
Radical de nous au présent → on retire -ons → on ajoute -ant
chantons → chantant · nourrissons → nourrissant · perdons → perdant
⚠️ Irréguliers : être → étant · avoir → ayant · savoir → sachant
→
En courant chaque jour, il a gagné en endurance.
moyen
→
Ayant froid, elle a fermé la fenêtre.
cause
→
Il travaille en écoutant de la musique.
simultanéité

Futur proche

✦ Projet imminent✦ Intention certaine✦ Futur proche

→

plan
→

imminence

Futur simple

Infinitif + -ai, -as, -a, -ons, -ez, -ont · Futur lointain, hypothèse
✦ Futur lointain✦ Promesse✦ Hypothèse (si + présent)
Radicaux irréguliers
être → ser- · avoir → aur- · aller → ir- · faire → fer- · voir → verr- · envoyer → enverr- · venir → viendr-
Exemple : envoyer
j'enverrai
tuenverras
ilenverra
nousenverrons
vousenverrez
ilsenverront
→
Dans dix ans, je vivrai à la campagne.
rêve lointain
→
S'il fait chaud, nous irons à la plage.
condition
✏️ Exercice – Futur simple

2. Nous (voir) nos cousins cet été.
3. Elle (pouvoir) te prêter son scooter.
4. Je (faire) les courses demain matin.
5. Ils (savoir) la vérité un jour.
  1. viendras
  2. verrons
  3. pourra
  4. ferai
  5. sauront

Imparfait

Habitude, description, contexte passé
✦ Habitude dans le passé✦ Description✦ Arrière-plan narratif
Formation
Radical de nous au présent + terminaisons -ais, -ais, -ait, -ions, -iez, -aient.
Nous chantions → je chantais, tu chantais, il chantait, nous chantions, vous chantiez, ils chantaient.
→
Quand j'étais petit, je jouais au foot tous les soirs.
habitude passée
→
La mer était calme et le vent soufflait doucement.
description
✏️ Exercice – Imparfait

2. Il (faire) toujours beau en été.
3. Nous (prendre) le train de 7h20 chaque matin.
4. Pendant des années, elle (vivre) rue des Lilas.
5. Vous (avoir) un chien blanc, n'est-ce pas ?
  1. écrivaient
  2. faisait
  3. prenions
  4. vivait
  5. aviez

Conditionnel présent

Radical futur + terminaisons imparfait · Politesse, souhait, hypothèse
✦ Politesse✦ Conseil✦ Hypothèse (si + imparfait)
Formation
Radical du futur + -ais, -ais, -ait, -ions, -iez, -aient.
Ex: je pourrais, tu devrais, il irait, nous serions, vous viendriez.
→
J'aimerais visiter Kyoto.
souhait
→
Tu ferais mieux de te reposer.
conseil
✏️ Exercice – Conditionnel
1. Vous (devoir) essayer ce restaurant.
2. Si j'avais le temps, je (venir) te voir.
3. (Pouvoir)-tu me passer le sel ?
4. Ils (vouloir) acheter une maison.
  1. devriez
  2. viendrais
  3. Pourrais-tu
  4. voudraient
