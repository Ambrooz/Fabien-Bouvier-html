01 Les bases

Qu'est-ce qu'une famille de mots ?

Des mots de la même famille partagent le même radical. En connaître un, c'est en deviner dix !

📌 Les trois éléments clés
Radical = la partie centrale qui porte le sens. Préfixe = avant le radical. Suffixe = après le radical.

02 Formation des mots

Les préfixes

Le préfixe se place avant le radical. Il modifie le sens — mais ne change pas la catégorie grammaticale.

❌ Préfixes de négation / contraire
Règle : Ces préfixes donnent le sens opposé ou négatif au mot de base.
in- / im- / il- / ir-
Contraire, négation — un- / nicht-
possible → impossible · légal → illégal · réel → irréel · actif → inactif
dé- / dés-
Action inverse — ent- / de-
faire → défaire · habiller → déshabiller · couvrir → découvrir
mal- / mé-
Mauvais, défaut — miss- / schlecht-
traiter → maltraiter · chanceux → malchanceux · content → mécontent
non-
Simple négation — Nicht-
violence → non-violence · fumeur → non-fumeur · sens → non-sens
🔄 Préfixes de répétition et d'intensité
re- / ré-
À nouveau — wieder- / nochmals
faire → refaire · lire → relire · écrire → réécrire · venir → revenir
sur-
Au-dessus, en excès — über-
charger → surcharger · estimer → surestimer · homme → surhomme
sous-
En dessous, insuffisant — unter-
estimer → sous-estimer · développé → sous-développé · marin → sous-marin
pré-
Avant, antériorité — vor-
voir → prévoir · historique → préhistorique · parer → préparer
trans-
À travers, changement — trans- / um-
porter → transporter · former → transformer · mettre → transmettre
em- / en-
Transformation — ver- / ein-
belle → embellir · riche → enrichir · fermer → enfermer

03 Formation des mots

Les suffixes

Le suffixe se place après le radical. Contrairement au préfixe, il change souvent la catégorie grammaticale.

🟠 Suffixes → NOMS
SuffixeSens🇩🇪Exemple

-mentaction, résultat-ung / -heitdévelopper → le développement
-ageaction, ensemble-ung / -evoyager → le voyage
-eur / -eusepersonne qui agit-er / -erinchanter → le chanteur
-teur / -tricepersonne qui agit-or / -eurcréer → le créateur

-essequalité abstraite-heit / -igkeitriche → la richesse

🟣 Suffixe → ADVERBES
Règle d'or : adjectif féminin + -ment = adverbe · auf Deutsch : meistens mit „-weise" oder das Adjektiv allein

Adjectifs en -ent → -emment : évident → évidemment (offensichtlich)
Adjectifs en -ant → -amment : courant → couramment (fließend)
Adjectifs terminés en voyelle : poli → poliment (höflich)
