Participe passé en -é ou infinitif en -er ?

Pour ne pas confondre, on peut essayer de remplacer par un verbe du 3ᵉ groupe comme "prendre" :

  • Si on peut dire "pris" → c'est un participe passé (en -é)
  • Si on peut dire "prendre" → c'est un infinitif (en -er)
للتمييز بين المصدر (infinitif) بصيغة -er والماضي التام (participe passé) بصيغة -é، يمكن استبدال الفعل بفعل من المجموعة الثالثة مثل "prendre" (يأخذ):
• إذا كان بالإمكان قول "pris" (أخذ) ← يكون الماضي التام (participe passé) بصيغة -é
• إذا كان بالإمكان قول "prendre" (يأخذ) ← يكون المصدر (infinitif) بصيغة -er
Exemple : "J'ai mangé" → on peut dire "J'ai pris" → donc c'est "mangé" avec -é.
Exemple : "Je vais manger" → on peut dire "Je vais prendre" → donc c'est "manger" avec -er.
مثال: "J'ai mangé" (لقد أكلت) ← يمكننا قول "J'ai pris" (لقد أخذت) ← إذن هي "mangé" مع -é
مثال: "Je vais manger" (سوف آكل) ← يمكننا قول "Je vais prendre" (سوف آخذ) ← إذن هي "manger" مع -er

Exercice 1 : -é ou -er ?

Complète avec la bonne terminaison :

1. Elle va chant une chanson.
2. Nous avons écout de la musique.
3. Il faut descend doucement.
4. Ils sont rest à la maison.

Réponses correctes :

  1. chanter (-er) → on peut dire "Elle va prendre"
  2. écouté (-é) → on peut dire "Nous avons pris"
  3. descendre (-re) → verbe du 3ᵉ groupe
  4. restés (-és) → participe passé avec "sont"

L'accord dans le groupe nominal (GN)

Dans un groupe nominal, le nom et l'adjectif s'accordent en genre (masculin/féminin) et en nombre (singulier/pluriel).

في المجموعة الإسمية (groupe nominal)، الاسم والصفة يتطابقان في الجنس (مذكر/مؤنث) والعدد (مفرد/جمع).
Exemple : "une vieille maison" → "vieille" s'accorde avec "maison" (féminin singulier).
Exemple : "des bracelets argentés" → "argentés" s'accorde avec "bracelets" (masculin pluriel).
مثال: "une vieille maison" (منزل قديم) ← "vieille" (قديم) تتطابق مع "maison" (منزل - مؤنث مفرد)
مثال: "des bracelets argentés" (أساور فضية) ← "argentés" (فضية) تتطابق مع "bracelets" (أساور - مذكر جمع)

Exercice 2 : Accord des adjectifs

Accorde correctement les adjectifs :

1. Une (vieux) femme.
2. Des colliers (argenté).
3. Un chemin (serré).
4. La maison (abandonné).

Réponses correctes :

  1. vieille → accord avec "femme" (féminin singulier)
  2. argentés → accord avec "colliers" (masculin pluriel)
  3. serré → accord avec "chemin" (masculin singulier)
  4. abandonnée → accord avec "maison" (féminin singulier)
💡 Astuce importante

Quand tu hésites entre -é et -er, chuchote "prendre" à la place du verbe. Ton oreille t'aidera à choisir !

عندما تتردد بين -é و -er، اهمس بكلمة "prendre" (يأخذ) مكان الفعل. سوف تساعدك أذنك على الاختيار!

Exercice 3 : Mots invariables à placer

Choisis le bon mot invariable pour chaque phrase :

1. Je vais un peu attendre.
2. du mauvais temps, nous restons.
3. Elle vient nous voir.
4. Il est le premier arrivé.

Réponses possibles :

  1. encore → pour indiquer une durée supplémentaire
  2. À cause → pour indiquer la cause
  3. régulièrement → pour indiquer la fréquence
  4. toujours → pour indiquer la permanence

📝 Texte à trous - Dictée d'entraînement

Complète le texte avec les mots manquants. Utilise le vocabulaire appris !

La (vieux) femme semble (isolé). Elle est restée (abandonner) dans cette maison pendant longtemps.

Sous le (soleil), son bracelet en (cuir) brille. Sa (ceinture) est serrée.

Pour (descendre) à la cave, l'escalier est (creuser) dans la pierre. C'est (impressionnant) !

Elle vient souvent nous voir. Nous l'attendons (toujours) avec joie.

Texte complet corrigé :

La vieille femme semble isolée. Elle est restée abandonnée dans cette maison pendant longtemps.

Sous le soleil, son bracelet en cuir brille. Sa ceinture est serrée.

Pour descendre à la cave, l'escalier est creusé dans la pierre. C'est impressionnant !

Elle vient souvent nous voir. Nous l'attendons toujours avec joie.

Bravo ! Tu as complété la dictée d'entraînement.
