🛒 Au marché

✨ Niveau A1 - Poser des questions et comparer ✨

📝 Dialogue : Sophie fait ses courses
👩 Sophie :
Bonjour ! Combien coûtent les fraises ?
👨 Le vendeur :
Bonjour madame ! Elles coûtent 5 euros le kilo.
👩 Sophie :
Et les framboises, quel est le prix ?
👨 Le vendeur :
Les framboises sont plus chères, 8 euros le kilo.
👩 Sophie :
Quelles sont les meilleures fraises ? Les grosses ou les petites ?
👨 Le vendeur :
Les petites sont les meilleures ! Elles sont plus sucrées.
👩 Sophie :
Bon, je prends un kilo de fraises. Où sont les tomates ?
👨 Le vendeur :
Les tomates sont là-bas, à côté des salades. Elles sont moins chères aujourd'hui !
👩 Sophie :
Parfait ! Pourquoi elles sont moins chères ?
👨 Le vendeur :
Parce que c'est la saison ! C'est le meilleur moment pour acheter des tomates.
👩 Sophie :
Quand est-ce que vous fermez ?
👨 Le vendeur :
Je ferme à 13 heures. Voilà vos fraises, ça fait 5 euros.
👩 Sophie :
Merci beaucoup ! À bientôt !

📖 Grammaire 1 : La forme interrogative

💡 Comment poser des questions ?

Il y a trois façons de poser des questions en français :

Type Structure Exemple
1. Intonation ⬆️
(le plus simple)		 Phrase normale + intonation montante Tu aimes les fraises ?
2. Est-ce que ❓
(le plus courant)		 Est-ce que + sujet + verbe Est-ce que tu aimes les fraises ?
3. Inversion 🔄
(plus formel)		 Verbe + tiret + sujet Aimes-tu les fraises ?

🔍 Les mots interrogatifs

Combien (How much/many) → Combien coûtent les fraises ?
Quel/Quelle/Quels/Quelles (Which/What) → Quel est le prix ?
Où (Where) → Où sont les tomates ?
Quand (When) → Quand est-ce que vous fermez ?
Pourquoi (Why) → Pourquoi elles sont moins chères ?
Comment (How) → Comment tu t'appelles ?
💡 Astuce : Pour les débutants, utilisez "est-ce que" + mot interrogatif :
• Où est-ce que tu habites ?
• Quand est-ce que tu travailles ?
• Pourquoi est-ce que tu études le français ?
📖 Grammaire 2 : Les comparaisons

⚖️ Comparer avec les adjectifs

Comparaison Structure Exemple
Supériorité ⬆️ plus + adjectif + que Les framboises sont plus chères que les fraises.
Infériorité ⬇️ moins + adjectif + que Les fraises sont moins chères que les framboises.
Égalité = aussi + adjectif + que Les pommes sont aussi bonnes que les poires.

🏆 Le superlatif (le plus / le moins)

Le/La/Les plus + adjectif → Les petites fraises sont les meilleures !
Le/La/Les moins + adjectif → Les tomates sont les moins chères aujourd'hui.
Le/La/Les meilleur(e)(s) → C'est le meilleur moment pour acheter !
Le/La/Les pire(s) → C'est le pire marché de la ville. (😞)
⚠️ Attention aux irréguliers :
• bon → meilleur (not "plus bon") → le meilleur
• bien → mieux (not "plus bien")
• mauvais → pire (or "plus mauvais") → le pire
✏️ Exercices pratiques

📝 Exercice 1 : Forme interrogative

Transformez les phrases avec "Est-ce que" :

1

Tu aimes les fraises. → _____________________________ ?

✅ Réponse : Est-ce que tu aimes les fraises ?
2

Vous fermez à quelle heure. → _____________________________ ?

✅ Réponse : À quelle heure est-ce que vous fermez ? (ou : Quand est-ce que vous fermez ?)
3

Les tomates coûtent combien. → _____________________________ ?

✅ Réponse : Combien est-ce que les tomates coûtent ? (ou : Combien coûtent les tomates ?)

📝 Exercice 2 : Les mots interrogatifs

Complétez avec : Où / Quand / Combien / Quel / Pourquoi / Comment

1

____________ sont les fraises ? → Elles sont là-bas.

✅ Réponse : Où
2

____________ coûtent les pommes ? → 3 euros le kilo.

✅ Réponse : Combien
3

____________ est-ce que vous fermez ? → À 13 heures.

✅ Réponse : Quand (ou : À quelle heure)
4

____________ elles sont moins chères ? → Parce que c'est la saison.

✅ Réponse : Pourquoi

📝 Exercice 3 : Les comparaisons

Complétez avec : plus... que / moins... que / aussi... que

1

Les framboises sont ____________ chères ____________ les fraises. (⬆️)

✅ Réponse : plus chères que
2

Les tomates sont ____________ chères ____________ hier. (⬇️)

✅ Réponse : moins chères que (ou : qu')
3

Les petites fraises sont ____________ sucrées ____________ les grosses. (=)

✅ Réponse : aussi sucrées que

📝 Exercice 4 : Le superlatif

Complétez avec : le/la/les plus... / le/la/les moins... / le/la/les meilleur(e)(s) / le/la/les pire(s)

1

Ces fraises sont ____________ (good - superlatif) du marché !

✅ Réponse : les meilleures
2

C'est ____________ (bon - superlatif) moment pour acheter des tomates.

✅ Réponse : le meilleur
3

Ces cerises sont ____________ (chères - superlatif) du marché.

✅ Réponse : les plus chères
4

C'est ____________ (mauvais - superlatif) marché de la ville.

✅ Réponse : le pire (ou : le plus mauvais)
